# Embedded Web Management Dashboard

Zigbridge features a self-contained, offline-first web management dashboard embedded directly into the compiled Go binary via `embed.FS`. It requires no Node.js runtime, no asset bundler, and zero external CDN connections.

---

## Dual-Mode Experience

Zigbridge is designed to serve both household family members and technical power users through an instant, one-click mode toggle.

```
+----------------------------------------------------------------------------------------------------+
| Zigbridge              (● Coordinator)   (● MQTT)   [OFF Advance]                                  |
+----------------------------------------------------------------------------------------------------+
|  [Devices]   [Bindings]   [Smart Suggestions]   [Activity]   [System]                              |
+----------------------------------------------------------------------------------------------------+
```

### 1. Simple Mode (Default)
Simple Mode presents a clutter-free, non-technical overview of your smart home devices:

- **Friendly Device Presentation**: Displays device icons based on inferred category (💡 Light, 🔘 Switch, 🏃 Motion Sensor, 🔌 Smart Plug).
- **Human-Readable Names**: Rename any device with one click to friendly names (e.g., *"Living Room Ceiling Light"*).
- **Qualitative Signal Indicators**: Instead of raw Link Quality Indicators (LQI numbers like `184`), devices show clean badges: `Excellent`, `Good`, `Fair`, or `Poor`.
- **Battery & Power Status**: Visual badges indicating remaining battery percentage or AC mains power.
- **Activity Feed**: Incoming events are translated into natural language:
  - *"Living Room Motion Sensor detected motion"*
  - *"Kitchen Switch turned ON Dining Table Lights"*
  - *"Bedroom Thermostat reported 21.4°C"*

### 2. Advanced Mode (For Engineers & Power Users)
Switching the header pill to **Advance Mode** (persisted across sessions via `localStorage`) reveals complete low-level Zigbee telemetry:

- **Hardware Addresses**: 64-bit IEEE MAC addresses (e.g. `0x00124B001CA20001`) and 16-bit Network IDs (NWK `0x1A2B`).
- **Cluster Hex Codes**: Discovered endpoints and Zigbee cluster numbers (`0x0000`, `0x0006`, `0x0008`, `0x0300`).
- **Raw LQI Metrics**: Exact integer Link Quality Index (`0` to `255`).
- **Live Frame Console**: A real-time terminal showing raw incoming and outgoing ZCL frames and JSON payloads received over WebSocket.
- **Diagnostics Tab**: Instant access to coordinator radio hardware, PAN IDs, transport health, and network telemetry.

## System Diagnostics Tab

Located directly to the right of the **Activity** tab, the **Diagnostics** view provides a full-page overview and detailed technical breakdown of your Zigbee mesh and host environment:

- **Coordinator Radio & Telemetry**: Model, driver type (`TI Z-Stack 3.x` or `Silabs EZSP`), IEEE 64-bit MAC address, and firmware build version.
- **Zigbee Mesh Parameters**: 16-bit PAN ID, 64-bit Extended PAN ID, and active 2.4 GHz RF Channel.
- **Transport & Host Connectivity**: Transport link status (`tcp` vs `serial`), MQTT broker connectivity, permit-join status, and system uptime.
- **Network Counters**: Connected device count, active direct binding count, and operational state.

## Dashboard Navigation Tabs

### Devices
Lists all paired devices in your Zigbee network. Allows renaming devices, checking online status, inspecting battery levels, and reviewing signal strength.

### Bindings
Visual manager for physical Zigbee direct bindings:
- Select a source switch/remote.
- Pick the cluster (On/Off, Level Control, Color Control).
- Select the target bulb or plug.
- Click **Create Direct Binding** to write the binding directly into hardware flash.
- Supports **Optimistic Binding** with non-blocking feedback for battery-powered devices.

### Smart Suggestions
Displays on-demand recommendations generated by Zigbridge's heuristic analyzer or external LLM:
- Automatically detects switches that frequently control the same bulb and suggests direct bindings.
- One-click **Apply** button to commit suggested bindings.

### Activity
A real-time timeline of Zigbee network events streamed over WebSockets (`/api/events`). In Simple Mode, events appear as clean human-readable action cards. In Advanced Mode, cards include raw JSON and hex payload inspectors.

### System
A dedicated, full-page view providing live radio telemetry, mesh network configuration, coordinator hardware specifications, and bridge transport diagnostics.

## Zero-CDN Offline Architecture

The frontend consists of:
- `internal/web/static/index.html` (Semantic HTML5)
- `internal/web/static/style.css` (Clean CSS with dark-mode aesthetic, zero CSS frameworks)
- `internal/web/static/app.js` (Vanilla ES6 JavaScript, zero npm packages)

Because all assets are compiled into the binary via `embed.FS`, the dashboard loads instantaneously and operates 100% offline without contacting external CDNs or Google Fonts.
